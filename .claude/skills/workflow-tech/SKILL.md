# Technical Design Route

`/workflow-tech <change>` routes to
[`planning-dev`](../planning-dev/SKILL.md). Technical design is Dev's first
artifact after QA1 freezes the blind cases. It is followed by scenarios,
tasks, QA2 reconciliation, human clarification, acceptance, and publication
as one planning run.

Do not run or accept a separate tech-design round. Resolve questions that can
change the requirements, approach, or tasks before acceptance.
