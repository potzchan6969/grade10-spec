# Technical Design Route

- **Route** - `/workflow-tech <change>` routes to [planning-dev](../planning-dev/SKILL.md). Pass the change and any technical-design input to its integrated planning run.
- **Completion** - Return that run's accepted and published plan, including `tech-design.md`, or its unresolved questions and blockers. Do not run a separate technical-design round.
