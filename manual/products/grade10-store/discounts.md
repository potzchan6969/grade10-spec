The store has no way to run a promotion. Shopify prices the catalogue and the
checkout, so a discount has to be Shopify's to be real — what this capability
adds is the store telling the truth about one: a discounted price shown where
the full price shows today, in the listing, on the product details page and in the cart,
never discovered for the first time at Shopify's checkout.

The intended shape: a price rule lives in Shopify, the storefront renders both
prices honestly while the rule runs, and the order of record keeps which rule
priced it — so the loyalty programme can decide whether discounted spend earns
points once, in one place.

Nothing here is specified yet. This page marks the roadmap slot; the propose
action on it is where the requirements start.
