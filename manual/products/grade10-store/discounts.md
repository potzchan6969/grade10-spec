## Today

The store has no way to run a promotion. Shopify prices the catalogue and
the checkout, so a discount has to be Shopify's to be real — and nothing in
the storefront can tell the truth about one yet.

## The intended shape

A price rule lives in Shopify, and the storefront renders both prices
honestly while the rule runs — in the listing, on the product details page
and in the cart, never discovered for the first time at Shopify's checkout.
The order of record keeps which rule priced it, so the loyalty programme can
decide whether discounted spend earns points once, in one place.

Nothing here is specified yet. This page marks the roadmap slot; the propose
action on it is where the requirements start.
