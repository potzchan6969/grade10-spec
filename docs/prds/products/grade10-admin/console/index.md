Grade10's operators work in one console over seven backends. Its furniture,
its visual standard and its account table are
[the shared console](/p/shared/console); the sections an operator works in
belong to the products behind them — [audit](/p/grade10-admin/audit),
[inventory](/p/grade10-admin/inventory), [auction](/p/grade10-admin/auction),
[vault](/p/grade10-admin/vault),
[appointments](/p/grade10-admin/appointment). This product is what the Grade10
console carries that neither supplies.

- **API docs** — the procedure record every Grade10 backend already declares,
  read off the routers and rendered for the engineers and reviewers who build
  against them
- **The Dev heading** — where a surface written for engineers rather than
  operators sits; staging and local builds carry it, a production build drops it
