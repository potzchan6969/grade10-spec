Every admin surface renders one component vocabulary — Astryx — and no surface
mixes two. The console package's blocks compose it, the product console
surfaces compose those blocks, and both application shells are built from it,
so an operator moving between nine consoles in a shift reads the same kinds of
fact arranged the same way in each.

A brand's identity reaches those surfaces through one theming mechanism and
nothing else: the same console under two brands differs only by theme, which
is how an operator recognises whose data they are acting on without either
brand forking the console. A component customers also see keeps one
definition, and the async, confirmation and selection semantics every console
already won survive any swap beneath them.

This standard governs appearance and the vocabulary that produces it, never
what an operator may do — that stays with each product's own capabilities. The
runtime underneath is held to terms rather than trusted: its version
discipline is a stated floor, and reverting it is a described route, not a
rediscovery.
