## ADDED User journeys

### shared-planning-agent-rounds-US-20: Designer finds their questions under their name

**As a** designer,
**I want** each question about a look to wait on me in one change for its capability, with the interim the feature ships,
**so that** I answer it from Pending in my own time and no feature waits on me.

### shared-planning-agent-rounds-US-21: Engineer builds the interim look

**As an** engineer building a feature,
**I want** the design to name the interim look the feature ships, built from the store's existing blocks and tokens, while the question about it is open,
**so that** I build now and a different answer reaches me as its own change.
