## ADDED User journeys

### grade10-admin-auction-featured-US-01: Operator fills a Featured slot

**As an** authorized auction operator,
**I want** to bind a published Active or Upcoming lot and upload one hero
image into an ordered Featured slot,
**so that** that slide leads the collector catalogue.

### grade10-admin-auction-featured-US-02: Operator orders and clears Featured slots

**As an** authorized auction operator,
**I want** to reorder up to three Featured slots and clear a slot that should
no longer lead,
**so that** `/auction` shows only the slides I still mean to feature.
