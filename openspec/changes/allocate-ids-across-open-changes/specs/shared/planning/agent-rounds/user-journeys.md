## ADDED User journeys

### shared-planning-agent-rounds-US-20: Hand issues an id beside another open change

**As the** hand who writes a delta or a suite on a capability another open change also adds to,
**I want** the next journey, scenario or case id to be one neither my branch nor the published `main` already holds,
**so that** no acceptance refuses my change for an id somebody else took.

### shared-planning-agent-rounds-US-21: Hand lands a branch second

**As the** hand who writes a delta or a suite on a branch worked beside another on the same capability,
**I want** my landing to name each id `main` already holds and the one command that moves mine above them, citations included,
**so that** I renumber a draft nothing else cites, never a contract on `main`.

### shared-planning-agent-rounds-US-22: Hand carries a case into a second change

**As the** hand who copies a scenario or a case into a second change,
**I want** it to keep the trace id it already holds,
**so that** a test that accepts it goes on accepting it.
