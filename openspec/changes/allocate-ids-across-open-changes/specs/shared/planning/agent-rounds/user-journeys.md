## ADDED User journeys

### shared-planning-agent-rounds-US-20: Engineer issues an id beside another open change

**As an** engineer writing scenarios on a capability another open change also adds to,
**I want** the next journey, scenario or case id to be one no durable spec and no open or archived change holds,
**so that** no acceptance refuses my change for an id somebody else took.

### shared-planning-agent-rounds-US-21: Engineer lands a branch second

**As an** engineer whose branch was worked beside another on the same capability,
**I want** my landing to name each id `main` already holds and the one command that moves mine above them, citations included,
**so that** I renumber a draft nothing else cites, never an accepted contract.

### shared-planning-agent-rounds-US-22: Engineer carries a case into a second change

**As an** engineer copying a scenario or a case into a second change,
**I want** it to keep the trace id it already holds,
**so that** a test that accepts it goes on accepting it.

### shared-planning-agent-rounds-US-23: Engineer folds a change written from the templates

**As an** engineer,
**I want** every form the change templates write to be folded through acceptance in CI,
**so that** acceptance never refuses a form the templates gave me.
