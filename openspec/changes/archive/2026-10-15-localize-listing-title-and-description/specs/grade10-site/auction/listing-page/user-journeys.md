## Context user journeys

### grade10-site-auction-listing-page-US-01: Collector opens a lot at its own address

**As a** collector,
**I want** a lot's address to answer with that lot's own page in the response
HTML,
**so that** I can read its name, its description and where its bidding stands
without waiting for a script to run.

### grade10-site-auction-listing-page-US-02: Collector shares a lot link

**As a** collector,
**I want** a lot link to unfurl as that lot and its own canonical address,
**so that** a link I pass on names the lot it points at instead of the auction
catalogue.

## ADDED User journeys

### grade10-site-auction-listing-page-US-16: Collector reads a lot's title and description in their own language

**As a** collector,
**I want** the card and the lot page to show the lot's title and description in the language I browse in,
**so that** I understand the card before I bid on it.
