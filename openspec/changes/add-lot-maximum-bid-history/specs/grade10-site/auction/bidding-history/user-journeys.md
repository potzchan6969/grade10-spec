## User journeys

### grade10-site-auction-bidding-history-US-06: Collector reviews maximum history on the lot

**As a** signed-in collector,
**I want** to open **Your bidding** on a lot and read every accepted maximum I
set or raised there,
**so that** I can see when I raised the ceiling without leaving the lot or
opening the full account chronology.

**Accepted by:**

- `grade10-site-auction-bidding-history-SC-42` — Collector opens maximum history on the lot
- `grade10-site-auction-bidding-history-SC-44` — Raised maximums appear on the lot without refusals
- `grade10-site-auction-bidding-history-SC-45` — Lot personal bidding stays private and inert

### grade10-site-auction-bidding-history-US-07: Collector reviews bids Grade10 placed on the lot

**As a** signed-in collector,
**I want** the lot dialog to separate the bids Grade10 placed for me from my
maximums, open on **Bid placed** by default, and list that tab first,
**so that** I do not read an auto-bid step as my authorized cap.

**Accepted by:**

- `grade10-site-auction-bidding-history-SC-42` — Collector opens maximum history on the lot
- `grade10-site-auction-bidding-history-SC-43` — Bid placed remains the default when bids exist
- `grade10-site-auction-bidding-history-SC-45` — Lot personal bidding stays private and inert

### grade10-site-auction-bidding-history-US-08: Collector reads clearer maximum labels on /bids

**As a** signed-in collector,
**I want** configure, raise, and refusal events on `/bids` named as maximum
set, raised, or refused,
**so that** the account chronology matches the lot wording without a new
account tab.

**Accepted by:**

- `grade10-site-auction-bidding-history-SC-46` — Account chronology names maximum set, raise, and refusal
