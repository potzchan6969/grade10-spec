## ADDED User journeys

### g10.store-order-detail.US3: Guest buyer returns from checkout to a confirmed order

**As a** collector who just paid as a guest,
**I want** my order page to confirm the order and name the email the receipt went to,
**so that** I know the store has my purchase and where to find it.

### g10.store-order-detail.US4: Guest buyer adds the order to a new account

**As a** collector who paid as a guest,
**I want** to add my order by continuing with the order email's Google account or sending a magic link to it,
**so that** it is listed with my other orders.

### g10.store-order-detail.US5: Link holder reads an order without signing in

**As a** person holding an order's private link,
**I want** the order page to open without needing a sign-in and without account facts,
**so that** I can follow the order the link was shared for.

### g10.store-order-detail.US6: Owner opens an order link while signed in

**As a** signed-in collector opening my own order's link,
**I want** to land on the order in my account,
**so that** I see it where my other orders live.
