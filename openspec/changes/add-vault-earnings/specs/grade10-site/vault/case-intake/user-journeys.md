## ADDED User journeys

### g10.vault-case-intake.US7: Owner hands in a binder of cards in one visit

**As an** owner bringing several cards to the shop,
**I want** them all taken into one case,
**so that** one visit and one signature cover every card.

### g10.vault-case-intake.US8: Operator sets each card's own terms

**As a** shop operator,
**I want** to give each card in a case its own effective start date, incentive rate and, where financed, financing term,
**so that** cards with different values and loans can sit together in one case.
