## User journeys

### grade10-admin-auction-listing-US-08: Operator compares interest across listings

**As an** auction operator,
**I want** to see how many collectors watch each listing from the Listings table,
**so that** I can tell which lots draw interest without opening each one.

**Accepted by:**

- `grade10-admin-auction-listing-SC-81` — The table shows a listing's watchers
- `grade10-admin-auction-listing-SC-82` — An unwatched listing shows zero
- `grade10-admin-auction-listing-SC-83` — A closed listing keeps its watchers
