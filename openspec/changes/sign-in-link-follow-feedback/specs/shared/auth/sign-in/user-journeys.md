## User journeys

### shared-auth-sign-in-US-06: Collector follows a link that cannot sign them in

**As a** collector who opened a sign-in link from email,
**I want** a clear toast on the brand home when that link cannot create a session,
**so that** I know whether to ask for a new link or that I cannot sign in at all.

**Accepted by:**

- `shared-auth-sign-in-SC-37` — An expired link toasts on the brand home
- `shared-auth-sign-in-SC-38` — A used link toasts that it no longer works
- `shared-auth-sign-in-SC-39` — A superseded link toasts that it no longer works
- `shared-auth-sign-in-SC-40` — An invalid link toasts that it no longer works
- `shared-auth-sign-in-SC-41` — A banned account's link follow toasts cannot sign in
