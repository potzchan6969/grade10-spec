## User journeys

### grade10-site-store-membership-US-07: Member carries their card in a phone wallet

**As a** member,
**I want** my card in Google Wallet, current and scannable without signal,
**so that** I am served from my lock screen instead of signing in and waiting for a code with a queue behind me.

**Accepted by:**

- `grade10-site-store-membership-SC-44` — A member adds their card to their wallet
- `grade10-site-store-membership-SC-45` — A pass identifies as the card does
- `grade10-site-store-membership-SC-47` — A pass identifies with no signal
- `grade10-site-store-membership-SC-52` — A recorded change reaches the pass
- `grade10-site-store-membership-SC-53` — A change nobody recorded reaches the pass
- `grade10-site-store-membership-SC-55` — A pass says how current it is
- `grade10-site-store-membership-SC-58` — The save action is offered beside the card

### grade10-site-store-membership-US-08: Member ends a pass they no longer want

**As a** member,
**I want** to end a pass and add a fresh one,
**so that** a phone I no longer have, or a code somebody photographed, stops working the moment I say so.

**Accepted by:**

- `grade10-site-store-membership-SC-46` — A photographed code is worth nothing
- `grade10-site-store-membership-SC-48` — Removing a pass leaves the membership intact
- `grade10-site-store-membership-SC-50` — An ended pass identifies nobody

### grade10-site-store-membership-US-09: Operator ends a pass for a member who asks

**As an** operator,
**I want** to end a member's pass at their request under the permission it requires,
**so that** a member without their phone is not left with a pass they cannot stop.

**Accepted by:**

- `grade10-site-store-membership-SC-51` — An operator ends a pass under the permission it requires
