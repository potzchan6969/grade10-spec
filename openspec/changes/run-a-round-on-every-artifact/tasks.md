# Tasks

Depends on `stage-changes-and-notify-hands` groups 1 to 5 for the record's keys, the team map, `contentIdOf`, `behindOf`, the record's rules and the surfaces this change adds rows to. Each group's tests land in their own commit before the group's code, and the test task's box is ticked last, once the code it names is pushed, wherever its number falls - as [Agent Rounds · The Walk](../../../docs/prds/products/shared/planning/agent-rounds.md#the-walk) asks. Group 6 is the application repository's, kept here so both boards read it.
