## ADDED User journeys

### zzz-site-auction-watchlist-US-01: ZZZ collector watches a listing to come back to it

**As a** signed-in ZZZ collector,
**I want** to mark a listing to come back to without bidding on it,
**so that** I can leave the page and find it again on ZZZ without searching.

### zzz-site-auction-watchlist-US-02: ZZZ collector returns to a listing from their watched list

**As a** signed-in ZZZ collector,
**I want** my watched listings in one place on ZZZ, most recent first, with
Unwatch beside each,
**so that** I return to a listing, or drop it, without searching.
