## 1. The name control (grade10-spec)

`ProductCard` already draws the name as a control wherever the tile opens
(`packages/ui/src/blocks/store-product-listing/product-card.tsx`), landed with
`add-store-cross-sell`. What it lacks is stories that cite these scenarios:
`NamedOnce` presses the name alone and counts two buttons, `SoldOut` spies on
no callback, no story omits both the callback and the address or gives the
address alone, and no list story checks which product a press names. The
photo is a second keyboard stop today, which Q6 removes inside a card; the
[tech design](tech-design.md#inside-a-card-the-photo-is-a-pointer-target)
says how.
