## User journeys

### grade10-site-e-kyc-identity-record-US-01: Collector uses one verified identity across their cases

**As a** collector who has already been verified once,
**I want** Grade10 to reuse that check on my next case,
**so that** I photograph my passport once, and an out-of-date check is caught
rather than quietly reused.

**Accepted by:**

- `grade10-site-e-kyc-identity-record-SC-05` — A second product reads a check the first recorded
- `grade10-site-e-kyc-identity-record-SC-07` — Re-recording a case replaces its identity
- `grade10-site-e-kyc-identity-record-SC-12` — An aged record is refused on reuse
- `grade10-site-e-kyc-identity-record-SC-17` — The last release purges the record and its evidence
- `grade10-site-e-kyc-identity-record-SC-18` — A record another case still binds survives a release
- `grade10-site-e-kyc-identity-record-SC-19` — A provider's copy is erased with ours
