## User journeys

### grade10-site-auction-auction-US-05: Collector reads the catalogue in one order

**As a** collector,
**I want** the catalogue to lead with the lots I can bid on, soonest to close
first, and to keep that order as I read on,
**so that** what I can still bid on is in front of me and reading further never
shows me a lot twice or skips one.

**Accepted by:**

- `grade10-site-auction-auction-SC-19` — Open lots lead the catalogue
- `grade10-site-auction-auction-SC-20` — Each status has its own order
- `grade10-site-auction-auction-SC-21` — A tie is settled the same way every read
- `grade10-site-auction-auction-SC-22` — Paging does not change the order
