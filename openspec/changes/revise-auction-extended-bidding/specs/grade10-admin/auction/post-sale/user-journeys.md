## User journeys

### post-sale-US-06: Operator sees which lots are still in extended bidding

**As an** auction operator,
**I want** the queue to label a lot still taking bids past its scheduled close,
**so that** I can tell a lot running long from one that closed on time.

**Accepted by:**

- `grade10-admin-auction-post-sale-SC-64` — A lot in extended bidding carries the label
- `grade10-admin-auction-post-sale-SC-65` — A lot not in extended bidding carries no label
- `grade10-admin-auction-post-sale-SC-66` — Extended bidding is not an outcome filter
