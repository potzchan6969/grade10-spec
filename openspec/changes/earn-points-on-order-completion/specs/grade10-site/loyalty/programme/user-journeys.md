## ADDED User journeys

### g10.loyalty-programme.US13: Member earns when the order completes

**As a** member,
**I want** my points to land when my order reaches Completed, on what it has paid then,
**so that** points never reward an order that could still be canceled or refunded before I have the goods.

### g10.loyalty-programme.US14: Member earns nothing on an order that never completes

**As a** member,
**I want** an order canceled or fully refunded before it completes to earn nothing,
**so that** my balance only ever grows for goods I kept.
