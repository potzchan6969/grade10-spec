# zzz

The ZZZ site's own surfaces — what belongs to the site rather than to a product
inside it.

- `navigation` — which surface an address resolves to, how the session corrects
  an address it decides, what a navigation preserves, and what code a surface
  costs.

Add another as `openspec/specs/zzz/<capability>/spec.md` — see the layout rules
in [`../README.md`](../README.md).
